# NautilusTrader

> Open-source algorithmic trading platform: a Rust-native core engine with a Python API for
> backtesting and live deployment of multi-asset, multi-venue trading systems from a single
> codebase.

## Key facts

- NautilusTrader is developed by Nautech Systems Pty Ltd.
- The open-source engine supports research, backtesting, simulation, and live trading workflows.
- The architecture uses an event-driven core, nanosecond timestamps, deterministic replay, and
  shared engine semantics between backtest and live environments.
- Python strategy code runs against performance-sensitive Rust components.
- NautilusTrader is trading software only. Nautech Systems is not a broker, dealer, exchange, or
  financial adviser.

## Integrations

Each page documents the adapter's supported products, order types, data feeds, execution features,
and quickstarts for one venue or data provider.

- [Architect](https://nautilustrader.io/architect/): Architect Exchange (AX) market data and perpetual futures on equities, FX, metals, and energy
- [Binance](https://nautilustrader.io/binance/): spot, USDT-margined, and coin-margined futures
- [BitMEX](https://nautilustrader.io/bitmex/): spot, perpetual swaps, futures, and spreads
- [Bybit](https://nautilustrader.io/bybit/): spot, linear, inverse, and options
- [Databento](https://nautilustrader.io/databento/): live and historical market data with L3 book depth and nanosecond timestamps
- [Derive](https://nautilustrader.io/derive/): on-chain options, perpetuals, and spot
- [Hyperliquid](https://nautilustrader.io/hyperliquid/): spot and perpetual futures
- [Kraken](https://nautilustrader.io/kraken/): Kraken Spot and Futures
- [Lighter](https://nautilustrader.io/lighter/): perpetual, RWA, and spot markets
- [OKX](https://nautilustrader.io/okx/): spot, margin, perpetual swaps, futures, and options
- [Polymarket](https://nautilustrader.io/polymarket/): CLOB market data and binary outcome markets
