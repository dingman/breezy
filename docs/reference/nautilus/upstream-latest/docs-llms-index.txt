# NautilusTrader Documentation

> NautilusTrader is an open-source, production-grade, Rust-native trading engine infrastructure for multi-asset, multi-venue trading systems. The docs cover architecture, deterministic simulation, live trading, integrations, and developer workflows.

Docs are versioned: latest tracks the current release; nightly tracks
the unreleased develop branch. Raw markdown for any page is available
under https://nautilustrader.io/docs/md/.
