# Polymarket US Connector Decision - Adversarial Peer Review

Artifact reviewed: `docs/plans/POLYMARKET_US_CONNECTOR_DECISION.md`

Review posture: independent adversarial review. NautilusTrader is immutable; use native extension mechanisms only. No authenticated calls, no POSTs, no credentials.

## Verdict

Requires a rewrite before implementation. The high-level conclusion "new Nautilus-native `polymarket_us` adapter, not repointed `.com` adapter" is sound, but the implementation plan proceeds too quickly into connector/execution work while settlement alignment, EV math, durable order state, secret containment, test egress safety, and bucket-level exposure controls are unresolved.

Proceed only after the amendments below are incorporated. No phase may imply patching, forking, or modifying Nautilus.
