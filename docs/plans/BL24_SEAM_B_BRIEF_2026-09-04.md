## 1. Parser — CREATE `src/breezy/ingest/nws_observations.py`

Precision rule, in this order:
1. `rawMessage` non-empty and `parse_metar_t_group(raw)` (import from `breezy.ingest.iem_observations:47`) returns tenths → `temp_c_tenths=<tenths>`, `is_metar=True`, `precision_c_tenths=5`.

3. else (non-integer value with no T-group, or `null`) → **DROP and COUNT** (`unparseable_row` / `null_temperature_row`). Never round.

Also here (pure, ingest-layer, no strategy import — see §3 note): `largest_gap_ns(sorted_observed_ns: Sequence[int]) -> int | None`.

`StationObservation` (`src/breezy/domain/station_observation.py:66-145`) requires `received_at_ns > observed_at_ns` strictly and `precision_c_tenths > 0`; its positive-lag guard is currently keyed on `source_channel == "iem_asos_metar"` (`:140`).
