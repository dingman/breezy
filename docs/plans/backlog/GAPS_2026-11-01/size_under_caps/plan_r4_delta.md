Live rests contribute 0 after a certified boot sweep (`_sweep_resting_orders_at_boot` `:8670` cancels every bound rest); if the sweep latches `resting_cancel_unconfirmed`, new orders are refused before any position headroom is read. RED tests `test_two_orders_each_under_position_cap_but_together_over_are_refused`, `test_prior_day_fills_count_toward_position_cap_after_restart` (its instrument is cache-only, NOT provider-loaded), `test_latched_sweep_refuses_before_position_headroom_is_read`.
