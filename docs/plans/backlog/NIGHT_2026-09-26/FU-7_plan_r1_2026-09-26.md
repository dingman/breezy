- **(A)** `InstrumentClose` is affected too, and the replay reads closes. Its truncated prefix is unlandable today as well, so there is no regression. Recovering it needs a table-level write, which is out of scope. Record it as a follow-up only if a truncated `instrument_close` file is ever observed.
