## Edge Cases & NFRs
- **Can backtest fills have qty≠1? Not by construction today.**
  - `CurrentRungHoldConfig` refuses `order_quantity != 1` (`src/breezy/strategy/current_rung_hold/config.py:263-266`).
  - `Take.quantity = inputs.config.order_quantity` on both legs (`decision.py:428`, :435).
  - Both backtest submitters use `make_qty(decision.quantity)` (`backtest_only.py:123`, `continuous_strategy.py:3307`).
  - `filled_trials_from_engine` keeps only `OrderStatus.FILLED` orders (`src/breezy/runtime/paper_replay.py:393`) and sets `qty=filled_qty` (:424). FILLED means `filled_qty ≥ quantity` (`base.pyx:1170-1173`).
  - A partial IOC ends CANCELED and is skipped, never a qty<1 trial.
  - The only residual path to qty≠1 is an over-fill (FILLED with `filled_qty > 1`), which `base.pyx:1170` does not exclude. AC1b is the defence in depth against it.
- **Live `qty ≤ 0`** is refused as `malformed_input` by `_validate_qty` (`score_live_trials.py:360-372`) before admission.
- **Live qty≠1** goes to `partial_fill`/`multi_fill` via `_admit_fill` (:402-415), before `pairs` is built. Today AC1a can fire only if that gate regresses.
- **qty>1 residual P&L** is already qty-scaled (`portfolio_roi_report.py:1091`, :1095). It is untouched.
- **Fee model:** `taker_fee_at_fill` (`fees.py:560-594`) uses banker's rounding per fill (`_round_bankers`, :597-605), which carries "error in both directions". AC4 is therefore labelled "modelled", never a bound.
  - At θ=0.0695, p=0.5: 0.017375 rounds to **0.02**. The fee rounds to 0.02 whenever θ·p(1−p) ≥ 0.015, i.e. p∈[~0.315, ~0.685].
  - At the pre-drift θ=0.06, p=0.5: 0.015 rounds half-even to 0.02.
  - The FU-3c "≤1¢/contract" claim therefore holds only outside that band. CFJ485874TMM at 0.70 gives 0.014595 → 0.01. **Erratum kept.**
- **Recorded fee > model** makes term (ii) negative. That is reported as is, never clamped.
- **θ unresolved** (AMBIGUOUS window or UNPINNED, `fees.py:521-530`): counted in (iii), excluded from (ii).
- **Price outside [0,1]:** `taker_fee_at_fill` raises `ValueError` (:588-592). It is caught per fill and counted in (iii) with a logged `trial_id`, so it never aborts the report.
- **NO leg:** the FilledTrial's `fill_px` is the leg's own paid price, the same value `score_trial` uses as cost (:206). p(1−p) is symmetric, so leg price inversion cannot change (ii).
- **Legacy-only sidecar line** (its trial is not in `residual_trial_ids_pooled`, :590-612, which reads per-family dirs only): the report books no P&L for that trial, so it gets no disclosure. It is dropped by the settled-residual join and logged by `venue_order_id`.
  - The legacy file is read **for dedupe only** and adds no booked row. The :596-605 docstring stays true for booking.
- **Sidecar says fee_unverified but the state DB now says `fee_reconciled=True`:** dropped. The state DB is authoritative, via the tuple `(fee_reconciled, venue_order_id, skip_ask_guard)`, `portfolio_roi_report.py:2992`, :3106-3110.
- **NFR:** read-only, no egress, no new DB pass. The disclosure reuses `family_station_results` (:3348), `residual_settlements` (:3454-3463) and sidecar reads.

## Design & Data Flow
**Consumers that assume per-contract `pnl`** (r1 table, unchanged):
- PREREG draw: `realized_draws.py:120-152` → `current_rung_hold_v2.py:337-345`.
- Tally: coherence (`family_tally_v2.py:328`), ROI bound (:566, `roi_bound.py:194-208`), stop-rule Σpnl (:878).

- Monitor and exit study: `position_monitor_nightly_report.py`, `current_rung_hold_exit_window_study.py:432`.
- Every one of these stays correct only if qty≡1 holds at **every** writer. That is why AC1b is not optional.

**Options:**
- **A. Scale `pnl` by qty (rejected).**
  - It is an L-2 unit change on a registered statistic.
  - It breaks the ROI-bound ratio and the payout identity.
  - It forces an edit to the per-contract fee test (L-12/L-46).
  - It fixes nothing, because no scored row can be qty≠1.
- **B. Add a nullable `qty` column (deferred).**
  - It would activate two dormant PREREG guards. YAGNI until the Increment B ruling.
- **C. Shared qty≡1 guard at both writers, label fix, Markdown-only disclosure (chosen).**
  - Zero stored or registered number changes, and zero JSON change.
- **Where the guard lives:**
  - It goes in `trial_scorer.py`, the module both writers already import (`score_live_trials.py:133-138`; `current_rung_hold_paper_replay.py:114`). One definition, no script-to-script import.
  - It is public (no leading underscore) because it crosses modules. It is pure and adds no import, so the settlement purity guard (`tests/unit/test_settlement_purity_guard.py`) is unaffected.
- **Why Markdown-only:**
  - `PortfolioRoiReportData` is documented as "Every field the D7 JSON sibling carries" (:2129).
  - The disclosure is therefore a separate frozen `FeeUnverifiedResidualDisclosure`, passed as an optional kwarg `render_markdown_report(data, *, fee_unverified=None)` (:2621). The existing call is `_run` :3551.
  - `_portfolio_roi_json_dict` is an explicit literal (:2312-2371, no `asdict`), so JSON is provably untouched.

**Flow:**
- **Live:** state DB → `_validate_qty` → `_admit_fill` (qty≠1 goes to residual) → **`assert_scored_pairs_are_unit_qty(pairs)`** → `score_trials` → sidecars/`write_scored_trials`.
- **Paper:** engine FILLED orders → `filled_trials_from_engine` → **guard** → `score_trials` → `write_scored_trials`.
- **Report:**
  1. Read the fee_unverified `ExcludedFill`s from the legacy top-level and every child dir.
  2. Dedupe them by `venue_order_id`.
  3. Map each `venue_order_id` to a `trial_id` via `fee_reconciled_by_trial_id` (flag False only).
  4. Keep only trials that have a `ResidualSettlement`.
  5. Compute (i)/(ii)/(iii) from the trial's FilledTrial and `taker_fee_at_fill`.
  6. Build a `FeeUnverifiedResidualDisclosure` and pass it to `render_markdown_report`.
