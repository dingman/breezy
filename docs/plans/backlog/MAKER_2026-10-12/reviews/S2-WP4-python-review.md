## HIGH
1. fill.py:133-147,162-177,142-143. A forecast release is a decision instant, but the new vector is promoted only AFTER the group (`staged` -> `vector`), so the selector at the release instant sees the OLD vector. The new forecast takes effect at the next depth/cut event, not at shifted_release+epsilon. A live bot would cancel (p_min) at release; here the rest survives, and prints between release and the next frame can fill it. Bias is fill-inflating. `Kind.DECIDE` (events.py:36) is declared and never used. Fix: emit a synthetic decision at `shifted_ts + 1 ns` (strict `<` satisfied) or promote the vector for a decision after the group; add RED test "release with no later frame cancels a rest whose p now fails".
2. fill.py:315-338,291-312. `_merge` takes end_ns/end_reason/vector/depth_ts from the BASE rest when a key exists in both passes. Stress fills later than base, so a row can have `filled_ns_stress > end_ns` (violates the plan "t0 < ts < end") and `p_yes_point_live`/`raw_sha256` are the vintage at the BASE fill, not at the stress fill. `scored_episodes.csv` scores filled_stress rows with p_yes_point_live (Test A). Fix: keep per-pass rests on Episode (end/vector per pass) or emit one row per (pass, rung, t0); test: base fills at t, vector changes, stress fills later -> stress row carries the later vector and end_ns >= filled_ns_stress.
3. fill.py:272-278,267. `assert_leak_free(depth_ts_used_ns=ts, t0_ns=ts)` is a tautology and `Episode.depth_ts_used_ns` records t0, not the frame's timestamp (a release-triggered decision on a 2 h old frame reports "used at t0"). `filled_ns=None` so the third assert never runs in the sim either. DepthFrame has no ts. Fix: carry `ts_ns` on DepthFrame/books (store (ts, frame)), pass the real frame ts, and call the assert at fill time with `filled`.
