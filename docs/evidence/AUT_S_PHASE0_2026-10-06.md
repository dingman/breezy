## 0.7 Take band: the live FQ rule has no ask band
- `executable_ask_lower/upper` (0.05/0.95) exist in `LadderEvConfig` (`strategy/ladder_ev/config.py:149-150`). FQ never reads them.
- **The FQ take condition** (`forecast_quantile_ladder/decision.py:283-355`):
  - YES side: `p_lower − ask − fee(ask) − 0.01 > margin(h)`;
  - NO side: uses `1 − p_upper`;
  - `margin(h)` = `0.02 + 0.04·clip((h−6)/18, 0, 1)` (`margin.py:30-37`).
- Any "take-eligible band" must be derived from this condition, which depends on the model's own probabilities.
